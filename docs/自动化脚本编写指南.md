# 基础版自动化脚本编写指南

本手册只描述当前基础版实际注册的10类、45个关键字。方法名、参数、默认值、返回值识别与源码一致；所有路径相对框架根目录，无源码行号。

## 编写规则

1. 功能模块优先封装Business，测试用例调用业务并设置明确断言。
2. TestCase使用 `info/config/step`；Business使用 `business/step`；前后置只有 `step`。
3. 业务输入使用 `参数名: {value: ..., path: ...}`；path以业务step数组为根，索引从0开始，必须命中实际字段。Business说明区的value不会自动注入step；调用方省略时用step原值。
4. Business不支持嵌套。原项目 `function: python`、`${变量名}`、`DataDriver.列名` 写法继续可用。
5. 参数传YAML原生类型；文本账号和密码加引号，布尔写true/false，数值按真实方法要求填写。变量完整占位保留对象类型，拼入文本时转字符串；不支持在占位符里执行Python表达式或自动读取环境变量。
6. 返回值关键字的 `params.result` 是框架虚拟参数；省略时保存到result，空值不保存。无返回值方法不可添加result。HTTP使用result_code/result_json/result_text/result_content；只有填写非空输出变量名才保存。
7. HTTP状态码保存为字符串，跨类型比较用string_equals；响应不是JSON时不要启用result_json。请求扩展键与method/url同级展开，不要包在kwargs下。
8. 原四个固定前后置文件使用 `.yml`，用例文件使用 `.yaml`，放testcase测试集子目录。每个用例结束会清理局部变量及相应Page/Session，不依赖前一用例状态。
9. 数据文件放 `testcase/casedata/datadriver/`。Excel第一行是表头，空单元格变空串、整数转字符串；使用 `DataDriver.列名`，表头避免空格和标点。
10. 基础版仅串行，没有外部Action插件和扩展关键字；新增业务优先用现有Action组合成Business。

## Python函数

```yaml
- function: python
  desc: 调用项目辅助函数
  params:
    py_name: helpers.py
    func_name: my_function
    kwargs:
      value: ${title}
    result: processed
```

此片段仅展示语法，使用前须在当前项目 `testcase/casedata/lib/helpers.py` 实现真实函数 `my_function(value)`。Function只在显式填写result时保存返回值，没有Action默认保存规则。

## Web公共参数

locator_type支持id、name、class/class_name、css/css_selector、xpath、role、text、label、placeholder、alt/alt_text、title、test_id/testid；kwargs是对应Playwright定位方法的辅助字典，不是任意动作参数。普通元素动作通常先等待可见；定位默认等待10000毫秒。只给声明了timeout的公开方法传timeout，不给click_element虚构该参数。

open_url对相对URL拼接项目test_url；switch_to_main_frame返回主页面，不是上退一层。download_by_click指定save_path可保存下载文件；screenshot返回bytes并按path可选落盘。

## HTTP公共参数

request的method/url必填，index默认为None。相对URL在index为真值时拼接test_url{index}，否则拼接test_url。headers/params/data/json/files/timeout和四个输出变量名在params内展开；timeout为正数秒，省略时按HTTP配置request_timeout读取，缺省30秒。verify由verify_tls配置覆盖。非2xx响应不会自动成为断言失败，必须检查返回结果。

| 业务名称 | 相对文件路径 | 输入参数及path | 输出变量 | 前置与清理 |

新增基础方法时，应同时提供真实实现、参数注释和返回类型，再按本手册的“用途、签名、参数表、返回、限制”格式补充；不引入已排除的外部Action插件机制。
